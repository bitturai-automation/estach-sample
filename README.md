# Estach — motion-led website redesign (concept demo)

A concept redesign of a digital marketing agency website, built as a portfolio demo.
**Unofficial** — not affiliated with or endorsed by Estach. The logo, client names, testimonials and videos belong to their respective owners and are used here only to demonstrate the design.

## Stack
- Vite + plain JavaScript (ES modules)
- GSAP + ScrollTrigger (scroll animations, pinned sections)
- Lenis (smooth scrolling)
- Hash-based routing: `#home #about #services #case-studies #blog #careers #contact`

## Run locally
```bash
npm install
npm run dev      # dev server
npm run build    # one self-contained dist/index.html
```

## Highlights
- Pinned "Work in motion" video strip that reveals one card at a time
- Pinned services stage that switches service on scroll
- Unified button system and spacing tokens across all pages
- Responsive layouts with a mobile menu
